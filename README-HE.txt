עדכון חלוניות זמני האירוע – אתר הברית

הקבצים בחבילה:
1. index.html – החלפת כרטיס השעה בכרטיס "זמני האירוע" ובתוכו שתי חלוניות.
2. admin.html – שינוי שם שדה השעה ל"שעת התחלת התפילה" והצגת הסבר.
3. assets/event-times.css – עיצוב החלוניות, כולל התאמה לטלפון.

העלאה ל-GitHub:
- החליפו את index.html ואת admin.html בקבצים שבחבילה.
- העלו את assets/event-times.css לתיקיית assets (קובץ חדש).
- אין למחוק או להחליף את assets/styles.css או את קובצי JavaScript.

לאחר העלאה:
1. היכנסו ללוח הניהול.
2. תחת "פרטי האירוע", בשדה "שעת התחלת התפילה", בחרו 07:30.
3. לחצו "שמירת פרטי האירוע".
4. רעננו את דף ההזמנה. חלונית "שעת הברית" תציג: "לאחר תפילת שחרית של שבת קודש".

העדכון משתמש בשדה time הקיים ב-Firestore, ולא מוסיף שדות חדשים. לכן אין צורך לשנות את Firestore Rules.
