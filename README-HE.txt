הזמנה לברית מילה — חבילת עיצוב ותיקון (15.11.2026)
=====================================================

החבילה מעדכנת את דף האורחים ואת דף המנהל. היא לא מוחקת נתוני Firebase.

העלאה ל-GitHub:
1. פתחו את https://github.com/avielbenshi-rgb/brit-invitation
2. העלו את הקבצים מה-ZIP תוך שמירה על הנתיבים (index.html, admin.html, assets/...).
   מומלץ לגרור את תוכן התיקייה, לא את קובץ ה-ZIP עצמו.
3. בצעו Commit changes והמתינו לפרסום GitHub Pages.
4. רעננו את דף האורחים ואת admin.html; במקרה הצורך פתחו בחלון פרטי.

קבצים להחלפה/הוספה:
index.html — עיצוב ההזמנה, ללא טקסטים מיותרים.
admin.html — ממשק מנהל מעוצב מחדש.
assets/invitation.css — עיצוב האורחים; מחליף את העיצוב הקודם.
assets/admin.css — עיצוב מנהל חדש, נפרד מהאורחים.
assets/guest.js — קריאת פרטי האירוע, קישור ניווט, RSVP וחץ גלילה.
assets/admin.js — ניהול מוזמנים, ייצוא CSV, שמירת הגדרות, חלונית עריכה ומחיקה.
assets/ceremony-hero.webp — תמונת האירוע הקיימת.
assets/favicon.svg — אייקון האתר הקיים.
firestore.rules — עדכון הרשאות שמאפשר לשמור גם את שדה mapUrl.

חובה נוספת ב-Firebase (GitHub לא מפרסם את הכללים):
1. היכנסו ל-https://console.firebase.google.com/ ובחרו בפרויקט brit-6e2a5.
2. פתחו Firestore Database > Rules.
3. החליפו את כל הכללים בתוכן הקובץ firestore.rules המצורף ולחצו Publish.
   אל תפרסמו כללים ציבוריים כגון allow read, write: if true.
4. ודאו שחשבון המנהל רשום במסמך admins/{UID} עם active=true.

הסיבה לעדכון הכללים:
הקובץ הקודם לא התיר לשמור את השדה mapUrl. לכן שמירה דרך המנהל עם
קישור Waze/Google Maps עלולה להיכשל ב-permission-denied. הכללים החדשים
משמרים הרשאות מנהל בלבד לקריאה/שינוי של RSVPs, ומאפשרים לאורח רק ליצור
אישור חדש בשדות המאומתים.

לא נוגעים ב-assets/firebase-config.js, ב-assets/firebase.js, במשתמשי Auth,
או באישורי ההגעה הקיימים ב-Firestore. אין צורך למחוק נתונים.

בדיקות מומלצות אחרי הפרסום:
- כניסה ל-admin.html, עריכת תאריך ושעה, ושמירת קישור ניווט.
- פתיחת index.html ובדיקה שהשעה, התאריך והמקום מעודכנים.
- שליחת אישור בדיקה, וידוא שהוא מופיע בניהול, ואז מחיקת אישור הבדיקה בלבד.
- בדיקת האתר בטלפון; אם רואים גרסה ישנה, רענון מלא/חלון פרטי.

הערה: בדיקות מקומיות אינן מוכיחות ש-Firebase החי הוגדר או שכלליו פורסמו.
