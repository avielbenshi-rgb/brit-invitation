חבילת הזמנה יוקרתית לברית מילה — מוכנה להעלאה ל־GitHub
=======================================================

זוהי חבילת עדכון לאתר הקיים, לא אתר Firebase חדש.
הקבצים כבר מסודרים באותם נתיבים שצריך להעלות למאגר:

1. index.html — להחליף את הקובץ הקיים בשורש המאגר.
2. assets/invitation.css — להוסיף קובץ חדש בתיקיית assets.
3. assets/guest.js — להחליף את הקובץ הקיים בתיקיית assets.
4. assets/ceremony-hero.webp — להחליף את התמונה הקיימת בתיקיית assets.
5. assets/favicon.svg — להחליף את האייקון הקיים בתיקיית assets (לא חובה, אבל מומלץ).

לא למחוק או להחליף את הקבצים הבאים:
- admin.html / assets/admin.js
- assets/firebase.js / assets/firebase-config.js
- firestore.rules
- מסמכי rsvps שכבר נמצאים ב־Firebase

שיפורים:
* עיצוב הזמנה חדש לחלוטין: קלף שנהב ממוסגר בזהב על רקע ירוק עמוק, טיפוגרפיה חגיגית ותמונה תואמת.
* פרטי האירוע ומיקום, תאריך ושעה מוצגים ככרטיס הזמנה, ללא חלוניות השעה הקודמות.
* שעת התחלה בלבד; הסרת ״שעת הברית״ וההערה שאחריה.
* השעה מתעדכנת ישירות מהשדה settings/event.time מתוך Firebase. שעת 07:30 מוצגת בטעינה כברירת מחדל.
* תיקון קריאת התאריך והשעה (שגיאת regex בקוד הישן).
* לחצן ניווט Waze/Google Maps מופיע כאשר קיים settings/event.mapUrl חוקי.
* לחצן צף עדין לגלילה לאישור הגעה, נע מעלה ומטה ונעלם כשאזור הטופס נכנס למסך.
* התאמת טופס והזמנה לטלפונים, ללא בריחת פיקסלים אופקית בבדיקות.
* הסרת ההודעה ״כבר נשלח אישור הגעה ממכשיר זה״ ושימוש ברישום RSVP רגיל.

חשוב לדעת:
- נתוני Firestore הקיימים אינם נמחקים. הסרת ההודעה המקומית אינה מוחקת אישורי הגעה מהשרת.
- אין כאן פרסום אוטומטי. יש להעלות את הקבצים ל־GitHub וללחוץ Commit changes.
- אחרי הפרסום ניתן לפתוח את האתר בחלון גלישה פרטית כדי לראות את העיצוב החדש ללא מטמון ישן.
- אם אין הרשאות קריאה למסמך settings/event או הרשאות כתיבה ל־rsvps ב־Firestore, יש לתקן את כללי Firebase בנפרד.

העלאה פשוטה:
1. לפתוח את https://github.com/avielbenshi-rgb/brit-invitation
2. להיכנס ל־Add file → Upload files (או לבחור Replace דרך העלאה), ולהעלות את 5 הקבצים עם מבנה התיקיות כפי שב־ZIP.
3. ללחוץ Commit changes.
4. לבדוק את אתר GitHub Pages.

בדיקות שבוצעו מקומית עם Firebase מדומה:
- בדיקת תאריך ושעה תקינים / שעת 07:30
- בדיקת קישור Google Maps
- בדיקת שליחת RSVP במבנה הקיים
- בדיקת חלונית תודה והסתרת החץ
- בדיקת גלילה אופקית בטלפון ובמחשב
- בדיקת היעדר שגיאות JavaScript בדפדפן

לא בוצעה בדיקת כתיבה בפועל ל־Firebase החי ולא בוצע פרסום ל־GitHub.
